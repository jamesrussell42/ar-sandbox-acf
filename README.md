# AR Sandbox for ACF Navigation Training

Augmented Reality Sandbox for map reading and navigation training.

Built on [Magic-Sand](https://github.com/thomwolf/Magic-Sand).

## Quick Start

```bash
# 1. Install: See docs/DEPENDENCIES.md
# 2. Clone: git clone <repo> C:\dev\ar-sandbox-acf
# 3. Setup: See docs/SETUP.md
# 4. Build: Open Magic-Sand.sln in Visual Studio, press F5
```

## Requirements

- Windows 7+
- Visual Studio 2019+
- Kinect v1 (Xbox 360)
- Projector (for actual sandbox)
