# Quick Setup

## 1. Install Dependencies
See `DEPENDENCIES.md`

## 2. Clone Repo
```bash
git clone https://github.com/yourusername/ar-sandbox-acf.git C:\dev\ar-sandbox-acf
cd C:\dev\ar-sandbox-acf
```

## 3. Download openFrameworks
Extract to: `C:\dev\ar-sandbox-acf\openFrameworks\`

## 4. Download Addons
```powershell
cd addons
git clone https://github.com/kylemcdonald/ofxCv.git ofxCv
git clone https://github.com/braitsch/ofxParagraph.git ofxParagraph
git clone https://github.com/braitsch/ofxModal.git ofxModal
git clone https://github.com/thomwolf/ofxDatGui.git ofxDatGui
```

## 5. Build
