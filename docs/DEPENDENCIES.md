# Dependencies

## Required (Install in Order)

1. **Visual Studio Community 2019+**
   - Download: https://visualstudio.microsoft.com/vs/community/
   - Install: C++ Desktop Development

2. **Kinect SDK v1.8**
   - Download: https://www.microsoft.com/en-us/download/details.aspx?id=40278
   - File: KinectSDK-v1.8-Setup.exe

3. **OpenFrameworks 0.9.3** (MUST be 0.9.3)
   - Download: https://github.com/openframeworks/openFrameworks/releases/tag/0.9.3
   - Extract to: `C:\dev\ar-sandbox-acf\openFrameworks\`

## Verify Kinect

- Plug in Kinect USB
- Device Manager → Look for "Xbox NUI Camera/Motor/Audio"
- All 3 should appear
